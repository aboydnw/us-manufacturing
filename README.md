# U.S. Solar Supply Chain

A source-transparent map explorer about what it takes to build a U.S. solar installation—and where the physical chain depends on other countries.

The interface moves through the physical process from raw materials to an installed project. Each stage maps verified active U.S. manufacturing facilities, separates nameplate capacity from actual output, and asks where U.S. supply comes from. Country flows and rankings appear only when one public, permissively reusable series uses the same product, period, unit, denominator, and origin definition. Until then, the interface says the answer is unknown and invites a better source.

The current map uses the Department of Energy's June 15, 2026 solar-manufacturing facility release. Country and state boundaries are checked-in public-domain data from Natural Earth and the U.S. Census Bureau, so the published site has no runtime tile or data service dependency.

## Local development

```bash
corepack enable
corepack yarn install
corepack yarn dev
```

The development server compiles the canonical files in `data/` into `public/data/site-data.json` before Vite starts.

## Verification

```bash
corepack yarn verify
corepack yarn test:e2e
```

`verify` checks formatting, lint, TypeScript, unit/component tests, content/provenance rules, and the production build. `test:e2e` uses Playwright and a virtual display to validate the real WebGL map at desktop and mobile viewports and refresh the reviewed screenshots in `docs/screenshots/map-redesign/`.

## Data workflow

- `data/source-registry.csv` is the canonical source inventory.
- `data/stages.json` defines the physical value chain and technology branches.
- `data/observations.csv` contains sourced quantitative claims.
- `data/reference-system.json` defines the engineering benchmark.
- `data/questions.json` contains genuine unknowns and their contribution prompts.
- `data/facilities.csv` contains normalized active DOE manufacturing locations. Numeric measures remain null when their products or units cannot share a meaningful stage scale.
- `data/supply-mixes.json` is the exclusive input for country rankings and flows. An empty array is an intentional unknown state, not missing application data.
- `public/data/site-data.json` is generated by `corepack yarn data:compile`; do not edit it directly.
- `public/data/countries.geojson` and `public/data/us-states.geojson` are generated, checked-in display boundaries.

See [the data-maintenance guide](docs/data-maintenance.md) before changing evidence or adding a source. The underlying source audit is in [the research report](docs/research/solar-supply-chain-source-audit.md).

## Deployment

The project is a static Vite site with no server functions or credentials.

- Build command: `corepack yarn build`
- Output directory: `dist`
- Framework preset: Vite

These settings are committed in `vercel.json`. Connect the GitHub repository to Vercel and deploy the feature branch as a preview before promoting `main`.

## Contributing data

The site deliberately displays important missing evidence as “We need data for this. Do you know of any?” Each prompt opens a prefilled GitHub issue. Sources must be publicly accessible and reusable; a public web page without clear reuse permission may be cited for context but cannot automatically become product data.
